HOW IT WORKS

From argument to settled pool in four steps.

01

State the terms

Write the question, pick the stake, set the deadline. Polyclone locks the exact wording so nobody can move the goalposts later.

02

Invite the pool

Share a link to your group chat. Everyone stakes YES or NO before the deadline hits — the pool locks automatically.

03

Reality decides

The outcome resolves against the source you named upfront — final score, closing price, or a neutral vote if it's a judgment call.

04

Payout, instantly

Winners get paid out of the pool automatically. No chasing anyone down, no "I'll send it later."
